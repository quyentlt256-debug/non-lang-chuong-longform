NÓN LÁ LONGFORM - FLASHCARD 8 THẺ

1. Đặt index.html và tất cả JPG, PNG, GIF, MP4 trong CÙNG MỘT THƯ MỤC.
2. Tải toàn bộ file lên cùng cấp thư mục gốc GitHub; các đường dẫn không có assets/.
3. Mở index.html bằng Chrome/Edge để xem thử.
4. Phần flashcard ở kỳ III: 5 ảnh cũ + 2 ảnh mới, thẻ thứ 8 là hình lá sen kèm câu kết biên tập.
5. Nếu muốn thay câu quote, tìm text 'Chiếc nón có thể đổi dáng' trong mảng const flashcards.
6. File MP4 có thể tải lên GitHub nếu dung lượng dưới ngưỡng; GitHub trình duyệt có thể giới hạn 25 MiB mỗi file.
